## §1 目标、方案取舍

第一波重开不是重写平台，也不是再发一版 CSS。**共同入口是一张会话工作面；A 把读的旅程做完整，B 把真实工作做完整。** 复用现有品牌、壳、Code bundle、投影和只读 host。左侧清楚地找会话，主区有标题、状态和正文；窄窗把同一导航做成可开的抽屉。只有经过审核的执行能力可用时，才显示输入、队列、取消、待审批等操作。

- **采用**：A 先落码，B0 同期做接口和权限评审；在 A 安装品可用且 B0 已锁定后接 B 实现。原因：先消除装不上、读不完、回不去的实机问题，同时不让上游接口风险拖住 A。
- 不采用只继续润色：无法修复滚动、恢复和真实运行缺口。不采用先接写操作再修读路径：会把产品恢复与执行安全混在一起，也会让演示掩盖核心断点。
- 范围保留：F8 交付物卡、F9 模型/权限设置骨架独立记账；无法交付时按原优先级明示差异，不得默删。F10 文件树可延；Office/Comic 和远程访问不在本波。

## §2 A 段合同（可按下列规格开工，仍需波前审计闭环）

1. **安装入口**：标准 npm tarball 内提供 Node `>=20` 命令 `atlasweb --scope main=<绝对的 AtlasCode 会话目录> [--port <端口>]`。保留现有 `--scope id=dir` 配置语义，首条验收固定显式 `main`；不扫描 HOME、不自行授权路径。采用自包含发布包：浏览器只使用 `dist/`，服务器和精确锁定的只读载体作为独立 Node bundle `server/atlasweb.js`；静态根只指 `dist/`。最终包无动态解析的 npm 运行依赖；载体精确 pin 保留在构建清单，包内元数据与 SRI 记录其版本和输入摘要。CLI 默认仅 `127.0.0.1` 临时端口，交付一次性打开链接；无源码仓、无 Bun、离线安装后也能启动。凭据不进日志、浏览器地址之外的持久化或截图；主动展示给操作者的单次链接是唯一例外。未经授权仍拒，用户可见重新从启动命令打开的指引。
2. **会话工作面**：宽屏列表，850px 有键盘可用的抽屉按钮，Esc 关闭并还焦；加载、空库、无命中、请求失败分别呈现。搜索点击携带同一 scope 下的会话和消息 ID，加载后将目标消息滚到可见区并标记。仅会话 ID 进 URL，浏览器 `sessionStorage` 按 origin/scope/session 记阅读锚，不存正文、令牌、搜索文本。刷新同一标签页恢复原会话和消息位置；删除或压缩导致锚不存在时明确提示并回到可用位置，不切换其他会话。
3. **长内容与连续性**：用真实测高和全范围占位的消息虚拟列表，保住滚动总高度与消息 ID 的映射；支持可变高正文、代码与活动。读历史时新消息不把视口拽到底，接近尾部时才跟随。重连按当前订阅代和已确认游标恢复；过期以基线替换，不重复合并旧事件。按浏览器实测验证。F6 原 page 补洞义务独立审视并保留；基线替换的测试不能代替缺页格，若需替代只按 S0 §3.2 另报裁。

## §3 B 段合同（产品需求已定，工程协议须 B0 冻结）

- 能力探测关闭时不提供写控件，只读面照常。显式授权的本机工作区，从浏览器新建或继续会话、提交一轮、查看真实增量输出；同会话有界 FIFO 等候、可取消 queued / active 项；一次提交不因重试多执行，完成/取消竞态只允许一个终态。浏览器展示在线执行，刷新后以持久化回读为准，不把 SSE 断连当取消。
- 执行是独立于只读 API 的正式接口。AtlasCode 持有工作区绑定、队列、授权、审批决策和日志；AtlasWeb 只编排 UI/本机 transport。程序可用接口以新版本受支持导出为准，不私引源码、Shell 拼接、解析 CLI 文本或由浏览器直写 JSONL。
- 审批事件绑定工作区、会话、回合和审批 ID；只允许唯一有效决定，拒绝/超时/取消不得执行待批操作；未授权、过期和跨域全拒。设置不能静默变更批准策略。F8 基于内核真实输出展示交付物，F9 展示受支持设置的有效值，不做空壳。
- B0 必交可核验的入口与实例生命周期证据、请求/事件结构、版本、上限和默认、重试/取消/审批时序、恢复、测试用隔离工作区设计。当前不预填不存在的路由名或宣称支持；B0 未锁不得开始 B1–B3。涉及放宽权限、变更既有安全矩阵或替代 F6 原义务才报用户，不能拿总体方向认可当具体安全批准。

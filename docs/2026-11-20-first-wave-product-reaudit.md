## 实施与重新验收的优先级

1. **先贯通只读路径**：从发行物启动 → 找到目标会话和消息 → 完整阅读长会话 → 刷新/断连后回来继续。常规窗口和 850px 窗口都能操作。浏览器对短、长、更新、断线、无凭据/失效状态分别给出证据。
2. **再贯通最小真实工作路径**：从 Web 在明确的工作区新建/继续会话 → 发送 → 看见真实流式输出 → 取消或完成 → 审批允许/拒绝 → 刷新仍能回读。只读路径与执行安全约束不得回退。先冻结详细工单和安全边界，再实施；UI 不直接写会话日志。
3. **验收在可重装的候选产物上做**：先证明 1/2 用户任务，再核通过套件/制品对表；不可用单张截图、绿色套件或新版本号替代任一任务。失败直接保留为产品缺口。

复核仅使用本机安装品与临时合成会话，无真实会话写入；本轮未改产品代码、未发布、未变更原本地服务。
